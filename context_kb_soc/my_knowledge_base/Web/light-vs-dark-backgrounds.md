# Light vs. Dark Backgrounds in Web Design

Based on the reference context, both light and dark backgrounds serve specific functional roles in web design.

### 1. Light Background with Dark Text (The Standard)
*   **Dominant Color:** White and Neutral Tones (60% of the design).
*   **Function:** Provides white space and reduces cognitive load.
*   **Impact:** Enhances readability and creates a clean aesthetic.
*   **Best for:** Information-heavy sites, blogs, and standard web pages where clarity is the priority.

### 2. Dark Background with Light Text (Dark Mode)
*   **Dominant Color:** Black and Dark Grays.
*   **Function:** Provides structure and high contrast.
*   **Impact:** Establishes visual hierarchy and can be used for brand identity.
*   **Best for:** High-tech branding, entertainment, or user preferences for reduced eye strain in low-light environments.

### Key Design Rule: The 60-30-10 Rule
When choosing a theme, apply the 60-30-10 rule:
*   **60%:** Dominant color (Background/Neutrals).
*   **30%:** Secondary color.
*   **10%:** Accent color (Primary Brand Color, e.g., Blue, for buttons and links).
